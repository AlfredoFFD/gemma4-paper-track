Runner (forks_modal_runner.py) differs from the Colab runner in three places, nothing else:
1. after the ARMS line: optional override, ARMS = os.environ['ARMS'].split(',') when ARMS is set (unset = the experiment's list)
2. 'platform': 'colab' -> 'platform': 'modal'
3. states file name read from STATES_FILE (default states.jsonl; an absolute path works)
EXPERIMENT stays hard-coded as 'C'; in other runs the arms field and the output directory identify the run.
