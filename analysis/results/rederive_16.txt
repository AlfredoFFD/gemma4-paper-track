   - Malformed call: fork_states.valid_call (the brief names it as the frozen rule; the pre-registration names gates_c.failure, which this script does not open), plus any tool outside the nine declared ones. A response with several calls is malformed if any one of them is.
   - Error: a row whose error field is non-empty. Neither a call nor a non-blank text: malformed.
   - graph_first counts a graph call anywhere in the response, not only its first call.
   - Share per arm = mean over tasks of the per-task share of 3 seeds (equal to the pooled share on complete tasks); each rule is the mean of per-task paired differences, resampled over tasks.
   - Verdict for W1 and W2 when the lower bound is not above 0: "not met". Underpowered applies when the rule is computed on fewer than 60 tasks; budget stop = fewer S and SC rows than tasks x 2 x 3.
   - Bootstrap percentiles by linear interpolation; a fresh generator per interval (seed 16016 + an md5 of the rule label), not the registered seed 0 routine.
   - Section 4 counts use the usable responses of the complete tasks; the graph_first share is also given on every usable response. Tool called first = the first call of the response.
   - Phrase = the stripped query holds whitespace. run_command search = the leading command (after cd) is grep, egrep, fgrep, rg, find or git grep; the count with a search anywhere in a pipeline is shown where it differs.
