5. JUDGMENT CALLS
   - The release resolver was read from the wheel data/wheelhouse/latest/swegemma-0.2.11-py3-none-any.whl; the path named in the task (data/wheelhouse/v28/src/...) holds swegemma 0.2.7, whose graph_utils.py has no resolve_node_name.
   - The resolver is re-implemented (every branch), not imported: the release imports networkx, numpy and cachetools. Its source in the wheel is pinned by sha256. It is given the graph as the list of node ids of the graph file, in file order (the order matters only for exact ties, which its third key, the id itself, breaks).
   - EDGE counts a pick as right whenever the TARGET is in the reach (the stored rule), even when other same-named nodes are in the reach too; the line "EDGE, shared" prints the expected count if such ties were broken uniformly.
   - RANDOM is the expected value (sum of 1/k), not a seeded draw.
   - NEAREST: "the file where the name appeared" is the file of the first read_file call (trace order, status ok) whose line range, in the snapshot text, holds the name as a whole identifier; the rule as worded in the task, not its fallback, was used. Every FORWARD pair has such a read. "Leading directory path" counts shared leading directory components (the file name left out); ties are then broken by being in the APPEARANCE FILE itself, then by the smallest node id. A same-named node whose id resolves to no file of the snapshot ranks last.
   - A node's file for NEAREST comes from analysis/nodes.resolve, so a same-named node that is not an ENTITY (no line span) still has a file.
   - "Without double-underscore names" uses the dunder rule of analysis/public_runs_lexical_reach.is_dunder (longer than four characters, starting and ending with two underscores), as the stored 158 does.
   - Section 3 asks the resolver for the TARGET's short name exactly as it stands; no other spelling (a dotted partial path, another case) was tried.
   - A share of a fractional count (RANDOM, the uniform tie lines) is the pooled sum over the pooled pairs, bootstrapped the same way as the counts.
