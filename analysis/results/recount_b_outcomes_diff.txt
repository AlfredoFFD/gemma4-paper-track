Independent recount of experiment B outcomes against the scorer used for the pooled table

Script: analysis/recount_b_outcomes.py (written from the pre-registration text; shares no scoring code).
This replaces an earlier note whose run read no snapshot text (loader bug, fixed).

The scorers agree on every read_file, edit_file and write_file call. They differ only on grep:
  pooled scorer     a grep counts when the command names the node's file and the pattern contains the node's name
  recount, file     also counts a grep on the node's file whose matched lines fall inside the node's span
  recount, wide     also counts a recursive grep over a directory that contains the node's file
The pre-registered text says "a shell view of that file overlapping the span or naming the node", so "file" is
the reading closest to the text and "wide" goes beyond it. All differences run one way (recount counts more).
