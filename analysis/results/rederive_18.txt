7. JUDGMENT CALLS
 1. A run enters if its arm has a result line for the task (the last line counts) and the error text is not an
    infrastructure failure by the rule of 14 (rederive_14.infra_kind). A rule uses the tasks where both of its
    runs entered; the four rules are computed on their own pairs, not on the tasks entered in all three arms.
 2. Shown every changed region: every CHANGED REGION of every GOLD FILE is overlapped by the lines of some view
    of that file, the same views that define 'shown a changed line' in 14: a read_file result with status ok
    (its returned start_line to end_line) or a shell view of one file (cat, head, tail, sed -n), lines as
    written. The outcome text of 18 says '(reads)'; read as read_file results alone the counts are printed
    beside it and as a sensitivity of U3.
 3. Patch touches every changed region: every CHANGED REGION of every GOLD FILE is intersected by a region of
    the agent's final patch in the same file, the agent's regions computed by the same parser on the same
    old-file numbering; an empty or missing patch is false.
 4. Traces. When the model makes several tool calls in one step, the trace stores the first result in that
    step's observation and the others in the 'system' steps that follow, in order (in every stored session the
    counts match and each read_file result names the file its call asked for). The calls are paired with those
    results here. The loader of rederive_14 gives such calls an empty result, so their reads are not seen; the
    counts with that loader are printed as a sensitivity. The CALL INDEX is the same under both.
 5. A note in the task statement of ON or OA does not count as being shown a line: only tool results do.
 6. Bootstrap: the per-task differences (first arm minus second, -1, 0 or 1) are resampled with replacement,
    random.Random(0) started afresh for each comparison, tasks indexed in run-list order with randrange; the
    interval is the 2.5th to 97.5th percentile of the resampled means, linear interpolation; 'more' needs the
    lower bound strictly above 0, 'fewer' the upper bound strictly below.
 7. Exact McNemar p: twice the smaller binomial(b + c, 1/2) tail at min(b, c), capped at 1; 1 when there is no
    discordant pair.
 8. Cut (a): the number of CHANGED REGIONS of a task is the count of hunk regions over its GOLD FILES (before
    the merging into places that the note of ON and OA uses). Cut (b): the share is over the task's CHANGED
    REGIONS, averaged over the runs that entered with equal weight per task. Cut (d): the call index of the view
    that completes the set (every call in the trace counts, from 1).
 9. 'tests_could_not_run' in a runner record, with test exit code 2 and an empty error text, is read as an
    outcome (the tests were collected against the agent's patch), not an infrastructure failure: the rule of 14
    decides from the error text.
