Ambiguities in the pre-registration texts and the readings taken here:
  A1. Interface failures: each row gets one class, checked in this order: error (non-empty error field), no call (next_call missing or empty), unknown tool (name outside the nine declared tools), malformed (fork_states.valid_call is False). Graph-tool calls with valid arguments are usable replays and never a touch.
  A2. Failure counts are over all rows of the run (every state); rates use usable replays of complete states only.
  A3. Complete state: the state is in the states file and every arm of the mode has a usable replay for seeds 1, 2 and 3. A repeated (state, arm, seed) row is counted and the first one is kept.
  A4. Rates are percent of usable replays on complete states (each replay weight 1); the bootstrap resamples states with replacement and takes the ratio of summed hits to summed replays. Contrasts are differences of these ratios on the same resampled states (paired by state).
  A5. Bootstrap: numpy default_rng(0), 2,000 resamples; percentile bounds are order statistics b[int(a*n)] and b[int((1-a)*n)-1] of the sorted resampled values (a = 0.025 for 95%, 0.05 for 90%), as in rederive_s5.py. The 90% interval uses the same resamples as the 95% one.
  A6. "Any unopened true neighbor touched": a replay counts if fork_states.touches returns read or edit for at least one name in the state's unshown_true_neighbors, with its span from neighbor_spans and the file's line lengths from nodes.file_text (exact character caps); graph returns do not count.
  A7. "Lower bound above 0" is strict. "Interval lies within plus or minus X points" is closed: both bounds in [-X, +X].
  A8. Fidelity: relative difference = (replayed - logged) / logged prompt tokens; rows with an error or a missing count are left out; the gate passes if the median of the absolute values is at most 2% (inclusive).
  A9. Thought text present: the thought field is a string that is non-empty after stripping whitespace. Completion and prompt tokens come from the usage field; replays without the count are left out of that line.
  A10. A failed gate or fewer than 200 complete states does not stop the script: the numbers are printed with an EXPLORATORY / NOT ANALYZED label so they can be compared.
  A11. D2 20% flag: interface failures of an arm divided by all rows of that arm in the run; flagged if strictly above 20%.
  A12. D2 "E true minus RE rewired": per replay, any unopened true neighbor touched under E minus any rewired entry (rewired_entries with rewired_spans) touched under RE, paired by state.
  A13. C, arm Ep: scored on all unopened true neighbors from the states file, including the swapped-out entry that the Ep note does not list ("every arm is scored with the same spans, whatever the note showed"). The variant that leaves the swapped-out entry out is printed beside it, labeled.
  A14. C secondary per-entry rate: pooled over (Ep replay, entry) pairs for the unopened true entries the Ep note lists (unshown true neighbors minus the swapped-out entry), clustered by state.
  A15. C1 and the decoy-versus-half rule use point estimates on the same complete states; the 1% floor is inclusive (swapped-out rate under E >= 1%).
  A16. C2 when G2 fails: no "only the full entry" verdict is given (the rule names it only while G2 holds); every C2 line is then EXPLORATORY.
  A17. G3: hosted H from results/v5, hosted E from results/v6, scored with the same states file; pairs are (state, seed) with a usable replay in both runs, on this run's complete states; difference = this run minus hosted, clustered by state. "Above 3 points" is read on the absolute point estimate.
