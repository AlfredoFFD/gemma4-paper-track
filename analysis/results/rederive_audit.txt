1. Patch parsing: per file block (--- / +++), hunks read by their line counts; "/dev/null" old side = new file (no units), "/dev/null" new side = deleted file (removed lines only). A file is Python iff its path ends in .py.
2. Patched file reconstructed by applying the hunks to the base text from the snapshot; context and removed lines checked against the base (mismatch count reported above).
3. Scopes from ast on base and patched files: FunctionDef, AsyncFunctionDef, ClassDef; a scope spans its first decorator to end_lineno, so decorator lines belong to the def. Innermost = deepest scope containing the line.
4. Ignored lines: blank (whitespace-only) and any line inside an Import/ImportFrom statement (multi-line imports included, inside defs too), judged in the file the line lives in. Comment lines count like code.
5. Added line whose innermost patched scope is not a qualname in the base file: walk up its chain to the nearest qualname that exists in base; if none, module-level (not a unit). Units dedup by (file, qualname).
6. Graph name: path minus .py, leading src/ or docs_src/ dropped, "/" -> "."; pkg/__init__.py tried as pkg and pkg.__init__; then the full class/def chain. If any ancestor is a function, also tried flattened to the nearest enclosing class (or the module). First candidate that is a node id wins.
7. Graph: <repo short>_<base_commit>.json; neighbors = union of in and out edges over unique node ids, self loops dropped; the 50 cap is on that unique-neighbor count. Task with no graph: no units addressable, no mentions.
