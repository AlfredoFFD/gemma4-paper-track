6. Judgment calls (where the written definitions left room)
     1. Path: the three prefixes are removed repeatedly; nothing else is cleaned. A read_file call without a
        string filepath would not be counted (there is none). A filepath that swallowed its bounds
        (path`,start_line:N) is kept as written, so it is a file of its own with no asked start: 38 first reads,
        of class OTHER.
     2. A read_file that failed is still a read, and still an earlier read of its file: 53 first reads have a
        result that is not ok (38 of them the swallowed paths above).
     3. Argument names: double quotes, single quotes, backslashes and whitespace are removed; a boolean is not
        an integer; if two names clean to the same bound the first integer wins (there is no such call). 5 first
        reads carry a mangled name.
     4. Viewer: a viewer name counts as a whole word (no letter, digit or underscore on either side) anywhere in
        the command, a quoted pattern included. A path-like token is a maximal run of letters, digits and _ . /
        ~ + @ % - .
     5. Whole path (PATH ONLY, and the command of way iii): not preceded by a letter, digit, _ . or - (a slash
        before it is a directory prefix, any directory, and is allowed); not followed by a letter, digit, _ or
        /, nor by a . or - that is itself followed by one of them. Ways (i) and (ii) use the same rule on the
        left. A path given in two pieces (ls of its directory, base name in the output) is not a whole path: 44
        such first reads are OTHER, 0 of them ask past line 1.
     6. Way (ii): path, double quote, optional comma, optional blanks, the word line, blanks, a number.
     7. Way (iii): the command is split into segments at unquoted | ; & ( ) ` and newlines. A segment runs a
        numbering program if an unquoted word (its base name) is grep, egrep, fgrep or rg followed in that
        segment by an unquoted --line-number or a one-dash group of letters and digits containing n (git grep is
        covered by its word grep); or is cat followed by such a group or --number; or is nl. Numbered lines may
        begin with blanks.
     8. GRAPH ADDRESS: only the lists neighbors, nodes and results at the top level of the result; lines is non-
        empty after stripping blanks.
     9. GRAPH NAME: the text of a graph answer includes the query or node it echoes (they are string values of
        the result); a path that does not end in .py keeps its extension in the dotted name.
    10. PATH ONLY in the command: the argument named command of the call just before, whatever the tool.
    11. Bootstrap: the tasks resampled are those with at least one kept episode in the scope; a task with no
        read in a class adds zero; both shares and the difference use the same resample; a resample in which a
        class has no read is left out; percentiles by linear interpolation; checks (a) and (b) are applied to
        the point shares, (c) to the lower end of the interval of the difference.
    12. Part 5: a listed range a-b is read as two integers; overlap is inclusive at both ends.
    13. Wording: the pre-registration gives words only for a rule that is met; the wording of a rule that is not
        met is mine.
