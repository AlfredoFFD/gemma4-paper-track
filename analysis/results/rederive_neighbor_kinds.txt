5. Judgment calls where the definitions left room (counts are over all paused steps unless said otherwise)
   1. Sections 0 to 2 cover every paused step of the states file, kept or not. Sections 3 and 4 cover the steps kept
      of each set and print, for reference, the UNOPENED ENTRIES by KIND on those steps.
   2. An ENTRY is one position of the printed list (steps without a printed list: 0; names repeated within a list: 0).
      Names in unshown_true_neighbors that are not in the printed list: 0; so the UNOPENED ENTRIES are exactly
      unshown_true_neighbors, the set the registered outcome is scored on.
   3. Quartiles: statistics.quantiles with method inclusive (linear interpolation between closest ranks).
   4. NO SPAN: no span record for the entry, or a record without an end (0 entries have a record that lacks an end, a
      start or a path), or a step whose node_span is missing or has no end (0 steps). For the registered outcome, "has
      a span" is read as in the starting scripts: neighbor_spans holds a record for the entry. UNOPENED ENTRIES of
      KIND NO SPAN: 0, so the two readings cannot differ on these data.
   5. CONTAINMENT: same path, (start, end) not equal, and one span inside the other, bounds allowed to coincide.
      Entries in the file of the entity just read whose span overlaps its span without containment: 0. Entries with
      exactly the span of the entity just read: 68; entries that are the entity just read itself (it is in its own
      list): 68, of them UNOPENED: 0. Such an entry is not CONTAINMENT (the spans do not differ) and goes on to the
      naming rules, where an entity names itself on its own definition line; their KINDS: CALLER AND CALLEE 68.
   6. UNOPENED ENTRIES that lie in the file of the entity just read are kept and scored like any other: 15
      (CONTAINMENT 8, CALLER AND CALLEE 3, CALLEE ONLY 4), in 8 steps, the steps where the run had not opened that
      file. Every UNOPENED ENTRY of KIND CONTAINMENT is among them, so a replay that opens the code of the entity just
      read can count there as reading a neighbor (the class around it, or its own method).
   7. NAMES is read on the text of the span as it stands, lines start to end inclusive: decorators, the definition
      line, comments, strings and docstrings all count, and nothing is parsed. So an entry whose last name component
      equals that of the entity just read names it, and is named by it, through the two definition lines alone.
      Entries other than the entity itself that share its last component: 11 (CALLER AND CALLEE 11), of them UNOPENED:
      11 (CALLER AND CALLEE 11).
   8. Identifier: a maximal run of ASCII letters, digits and underscores that starts with a letter or an underscore (a
      run that starts with a digit holds no identifier). Entries whose KIND changes if letters and digits are any
      Unicode ones: 0 (0 UNOPENED); if an identifier may start inside a run that begins with a digit: 0 (0 UNOPENED).
   9. File lines: the text from nodes.file_text split on LF, newline excluded, a final empty piece after a trailing
      newline dropped (as in rederive_12.py; rederive_cd.py uses splitlines). Files where the two ways differ: 0;
      files of a span missing from the snapshot: 0; spans that reach outside their file: 0.
   10. TEST CODE is decided by the dotted name alone, as written (a component test or tests that is not the first
       counts only in the form .tests.). Entries that are not TEST CODE by the name but whose file path has a
       directory test or tests, or a file named test_*.py, *_test.py or conftest.py: 0 (0 UNOPENED); entries that are
       TEST CODE by the name with no such path: 0.
   11. USABLE REPLAY: failure classes in the order error, no call (no next call, or one without a function name),
       unknown tool (not one of the nine tools), malformed (valid_call false); a replay counts once. A valid call to a
       graph tool is usable and is never a read. A repeated (step, arm, seed) row would keep the first; a row whose
       step is not in the states file is left out.
   12. STEPS KEPT, first set: all 10 arms present in the three files (A, P, Pp, H, Hp, D, Dp, E, RD, RE) must be
       usable for seeds 1, 2, 3, not only the 6 arms that enter a DIFFERENCE (with only A, H, D, E, RD, RE the steps
       kept would be 395). Every arm is scored on the UNOPENED ENTRIES of the true list, whatever the arm itself
       showed the model.
   13. READS A NEIGHBOR'S CODE: touches returns something other than None and 'graph' for at least one UNOPENED ENTRY,
       called with the line lengths of the entry's file. Values returned over all the calls scored in sections 3 and
       4: 'graph' 15, 'read' 867, None 155430.
   14. One call can touch several UNOPENED ENTRIES. The split counts a replay under every kind it touches, so the kind
       columns may add to more than the reads, and "reads a caller", "reads a callee" and "another kind" are not
       exclusive by construction. "Another kind" is CALLER AND CALLEE, CONTAINMENT, NEITHER or NO SPAN. "Reads a
       caller" takes CALLER ONLY entries in TEST CODE and in other code together. "More than one kind" is given three
       ways because the text does not say which.
   15. Shares pool replays: replays with the outcome over all replays of the arm on the steps kept (steps times seeds;
       a step kept has one replay per seed in every arm). A DIFFERENCE is paired: both arms on the same steps and
       seeds.
   16. Bootstrap: random.Random(seed).choices over the steps kept, sorted by task, run and fork; seed 731953 for the
       first set and 731954 for the second; 2000 resamples, one set of resamples per set of replays, shared by every
       DIFFERENCE and outcome; each resample divides its summed difference in hits by its replays. Percentile bounds
       are the 51st and the 1,950th of the 2,000 sorted values, as in the starting scripts. One hit is 0.09 points in
       the first set and 0.08 in the second, and a bound that sits one hit from zero can land on zero under another
       seed (table f gives the range of each bound).
   17. Tables (e) and (f) are additions of this script: counts of steps and tasks behind each outcome, the bounds
       under 20 other seeds (seed + 1000, + 2000, ...) as a rough guide to the Monte Carlo error, and intervals with
       whole tasks resampled (seeds 831953 and 831954; a resample divides by its own number of replays), since the
       steps of a task are not independent.
   18. Second set: arm E is restricted to the steps kept where E too is usable for the three seeds, so its shares are
       on fewer steps; E enters no DIFFERENCE there.
