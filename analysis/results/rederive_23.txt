 1. Entered: the arm has a result line for the task (the last one counts) and its error text is not a failure
    outside the agent by the rule of 14 (rederive_14.infra_kind). Each rule uses the tasks where both of its
    runs entered; the floor of 80 tasks is applied to that count (for A1 also 20 tasks with an A1 READ in both).
    Verdicts are printed only when G0 is met (both shares at least 80%) and the floor is reached.
 2. Calls are paired with their own results (rederive_18.load_calls_paired); the CALL INDEX counts every tool
    call of the trace from 1. A READ is a read_file call whose result has status ok; its FILE is the result's
    filepath (the argument's if the result names none) without a leading /workspace/, workspace/ or ./.
 3. START: none when no argument whose letters, lower-cased, spell 'startline' is given; otherwise the
    start_line the result returned. A READ starts past line 1 when START > 1; a READ with no START counts as not
    past line 1. LINES READ: returned end_line - start_line + 1 summed over READs (the returned range, not the
    content of a read cut by the character limit). READs of a file the run itself wrote count (the definition
    excludes nothing); the count without them is printed beside A2 as a sensitivity.
 4. PUSHED LIST: a READ whose result in the trace carries the key 'code_graph'. The k-th pushed list of the
    trace is matched to the k-th push of the runner record (extra.jsonl 'pushes'), checked by (source, name) of
    every entry; the entry's file and line range come from the record (for PE also checked against the trace).
    The push's CALL INDEX is that of the READ that carried it. Characters: the length of the key's value as the
    trace holds it, re-serialised with json.dumps(ensure_ascii=False) (the runner's own count is checked against
    it). Entries per list are the entries of the record.
 5. A1 READ: for each file that holds an entry of a pushed list of the run, the run's first READ of that file,

 7. Resolved: the result line's resolved field. Shown every changed region, shown a changed line within 8 calls

10. Bootstrap: per-task differences resampled with replacement, random.Random(0) started afresh for each
