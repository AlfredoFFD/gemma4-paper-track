# Pre-registrations

One file per experiment we will report, named `NN-short-name.md`, committed **before** the data it governs exists.
Each file states:
- the question
- the arms or conditions
- the tasks and sample
- the primary outcome and secondary outcomes
- the statistical test
- the decision rule (what result means what)
- the controls
- what counts as exploratory

Changes after the first commit are dated amendments appended at the bottom, with a reason. They are never silent
edits. The git history is the timestamp.
