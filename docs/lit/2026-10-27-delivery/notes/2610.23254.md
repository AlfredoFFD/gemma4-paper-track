# Ignored, Not Refused: What Low Prompt-Injection Success Rates Hide in Small Tool-Using Agents

- **arXiv:** 2610.23254 (v1, 16 Oct 2026, cs.CL, CC BY-NC-SA 4.0)
- **Authors:** Farhan Zarif, Kazi Shahid Ahmed Galib, Synthia Akter Promi, Shabnam Sharmin Tarin, Ariyan Hossain, Sadif Ahmed, Farig Yousuf Sadeque (BRAC University)
- **Version read:** v1, full text (HTML-derived txt, 1,763 lines) plus the 17-page PDF, read 2026-10-27
- **Artifacts:** anonymous.4open.science/r/AgentAutopsy-15C4/ holds the 33,000 labeled trajectories, the judge prompt, quote-verification code and analysis scripts (App. B)

## Verdict on overlap

This is an indirect prompt injection (IPI) audit of small tool-using agents, not a coding or graph paper. Its value to us is C5: it separates "the agent said it recognized X" from "the agent acted on X" with verified chain-of-thought quotes, on 11 small open models that include two Gemma 4 models (E4B and 12B) and NF4 4-bit serving. It also shows that the same visible tool-output content is acted on at 0.2% or 43% depending on a system-prompt framing block. That is a framing moderator our push condition has to control. It does not cover C2 (pull vs push), C4 (forks), the base-rate part of C3, or C6.

## Claim (key numbers and where)

1. **Failed attacks are mostly ignored, not refused.** Of benchmark-scored failures, the agent ignored the injection in 76.3% (AgentDojo, n=14,699) and 80.3% (InjecAgent, n=15,274). Genuine Refusal was 18.0% [17.4, 18.6] and 17.2% [16.6, 17.8]. 9/11 (AgentDojo) and 10/11 (InjecAgent) agents ignore more than they refuse. Sources: §4.1, Table 2, Table 9.
2. **Recognition is not resistance.** The judge flagged stated recognition in 4,740 AgentDojo and 5,688 InjecAgent trajectories (28.7% and 34.5% of audited ones). The attacker's action was still executed in 28.9% [27.7, 30.2] and 16.9% [16.0, 17.9] of those. On AgentDojo this ranges from 82.6% (Ministral-14B) to 2.0% (Ornith-9B). Sources: §4.1, Table 4.
3. **Low ASR is an untriggered default, not an enforced boundary.** On 10,698 InjecAgent cases run under both policies, an "Authorize" system-prompt block (tool-output instructions are tasks) gives ASR 43.05% [42.11, 43.99], against 8.09% at baseline. A matched "Interdict" block gives 0.22% [0.15, 0.33]. Nine agents shift significantly (McNemar, Bonferroni-surviving). Sources: §4.2, Figure 2, App. E.
4. **Safe is not useful.** In 21.7% of 16,273 audited AgentDojo episodes, the attack failed and the user task also failed (S0U0, "Safe but Dysfunctional"). ASR counts these as defenses. Sources: §4.3, Figure 3a.
5. **Quantization lowers ASR by weakening agents, not by defending.** Pooled InjecAgent ASR goes 8.09% (FP16), 7.50% (FP8), 6.35% (NF4), while refusal rates stay flat (Table 9). At NF4, Qwen-4B's invalid outputs rise from 19 to 115. On AgentDojo, NF4 cuts ASR by 2.33 points but cuts Safe-and-Useful by 3.97 and UA by 4.75 (§4.2).

## Method (enough to reproduce)

- **Threat model.** The attacker controls only external content that reaches the agent through tool outputs. It cannot touch the system prompt, the user request, the tools or the model (§3).
- **Benchmarks.**
  - InjecAgent: 1,054 two-turn cases (510 Direct Harm, 544 Data Stealing), base setting, official ReAct prompt and output parser. Data Stealing is scored at the attacker's data-access call.
  - AgentDojo: the `tool_knowledge` attack, 949 attacked episodes (984 minus 35 capability-only) over the Banking, Slack, Travel and Workspace suites, plus 97 clean tasks for Benign Utility (App. A).
- **Serving.**
  - vLLM 0.25.1, greedy decoding (temperature 0, top-p 1, fixed seeds), 16,384-token chunked prefill, 65,000-token maximum length, 8-turn limit per episode.
  - Precisions: FP16; FP8 weight-only (W8A16, Marlin kernels); NF4 (bitsandbytes, block size 64, double quantization).
  - Gemma-4B, Gemma-12B and Qwen-4B use a text-JSON tool wrapper; the other agents use native function calling.
  - No grammar-constrained decoding, loop detection or fine-tuning, "because each would hide the failures we measure" (App. A).
- **Audit sample.** A locked stratified random sample of 500 trajectories per cell, over 66 cells (11 agents x 3 precisions x 2 benchmarks), so 33,000 in total. AgentDojo is stratified by suite in proportion to size (76/55/74/295); InjecAgent by attack class (258 Data Stealing / 242 Direct Harm) (App. A).
- **Judge.**
  - DeepSeek-V4.1-Flash, greedy, 8,192-token completion limit. It is chosen because no audited agent is from its family, which avoids self-preference.
  - Input: user task, full injected instruction, attacker goal (tool plus arguments), and the trajectory as JSON inside an untrusted-data block. Benchmark verdicts are removed and model names hidden.
  - Output: one of six precedence-ordered labels, in order Full Compliance, Partial Compliance, Genuine Refusal, Inert-Recognized, Inert-Unrecognized, with Mechanical Breakdown as a conditional override.
  - It also returns a recognition flag, the first recognition step, a verbatim evidence quote, a justification and a confidence (App. D).
- **Quote verification.**
  - A recognition or refusal claim must quote the agent's reasoning. A script checks that the normalized quote is a substring of the normalized reasoning, and re-asks the judge up to twice.
  - If the check still fails, recognition is set false and the label becomes Inert-Unrecognized.
  - Of 10,428 recognition claims, 9,466 (90.77%) passed on the first attempt (App. D).
- **Four-way grouping.** Compliance (Full plus Partial), refusal, ignored (Inert-R plus Inert-U), breakdown. The main claims use this grouping.
- **Deployment conditions** (each changes one thing; every case is compared with the same case at baseline):
  - Interdict vs Authorize: 163 vs 172 words, same template, opposite direction. InjecAgent, 11 agents, FP16, 10,698 cases.
  - Source-boundary guardrail: 182 words, three rules. InjecAgent, 9 agents (not MiniCPM-2B or Spark-4B), 9,458 cases.
  - Precision: FP8 and NF4 on both benchmarks.
  - Exact prompt blocks are in App. C.
- **Statistics.**
  - Wilson 95% intervals.
  - McNemar on discordant pairs (exact binomial when N01+N10 < 25, Edwards continuity-corrected chi-square otherwise).
  - Pearson chi-square with Cramer's V for associations, and Bonferroni over the reported tests (App. E).
- **Frontier reference.** Kimi K3, one FP16 run on both full benchmarks, audited the same way (App. F).

## Metrics (exact definitions)

- **ASR.** The share of attacks whose attacker goal is reached. InjecAgent's invalid outputs (not readable as a tool call) count as failed attacks.
- **BU and UA.**
  - BU: completion rate on the 97 clean AgentDojo tasks.
  - UA: share of attacked episodes with U=1, whatever the attack outcome.
- **NRP** (from ASB): PNA x (1 - ASR), with PNA taken as BU.
- **ATOM.** The joint (S, U) cell per AgentDojo episode:
  - S0U1 Safe and Useful
  - S0U0 Safe but Dysfunctional
  - S1U1 Unsafe but Useful
  - S1U0 Unsafe and Hijacked
- **Recognition.** The judge flags it only when the agent's reasoning explicitly names or parses the injected text as an instruction addressed to the agent, backed by a verified verbatim quote. Quoting the injection as data is not recognition.
- **Rec. and Exec.|Rec.** (Table 4)
  - Rec.: % of all audited trajectories with recognition.
  - Exec.|Rec.: % of recognized trajectories in which the attacker's action still ran.
- **Failure composition** (Table 2): % of benchmark-scored failures in each label. Partial and Full Compliance rows inside "failures" are judge-benchmark disagreements.

## Results, including weak and negative ones

- **Baseline at FP16** (Table 3).
  - Pooled ASR 8.09% (InjecAgent) and 11.96% (AgentDojo); BU 77.88; UA 72.73. Eight of 11 agents are under 10% InjecAgent ASR.
  - The highest AgentDojo ASR is Gemma-12B (27.61%), then Qwen-4B (25.18%) and Ministral-14B (22.55%).
- **Invalid outputs confound low ASR** (Table 3, App. F).
  - 1,562 FP16 InjecAgent outputs were invalid. LFM-2.6B has 0.00% ASR with 735/1,054 invalid, so most of its cases never test resistance.
  - Four agents produce 1,430 of the 1,562, each dominated by one error type, and only 8 of those contain a call to the attacker tool. Over valid outputs only, pooled ASR is 9.35%.
- **Exceptions to "ignored more than refused."**
  - Ornith-9B refuses 83.6% (AgentDojo) and 71.9% (InjecAgent) of failures.
  - Spark-4B on AgentDojo refuses 47.6% against 46.4% ignored (Table 2).
- **Robustness of the composition** (Table 9). Ignored > refused under every check: FP16-only, FP8-only, NF4-only, high-confidence-only, valid-outputs-only, suites weighted equally (68.9/23.6), and a worst case that moves 22.7% of ignored to refused (53.6/40.7 and 57.6/39.9).
- **Gemma 4 specifics** (Tables 2, 3, 4, 11; Figure 2).
  - Gemma-4B (E4B): Rec. 40.3% / Exec.|Rec. 43.1% on AgentDojo; 36.5% / 18.1% on InjecAgent. Its AgentDojo FP16 cell shows recognition in 34.4% of trajectories, with 41.3% [34.2, 48.8] (71/172) executed anyway (App. F).
  - Gemma-12B: Rec. 13.9% / Exec.|Rec. 67.5% on AgentDojo; 55.6% / 3.7% on InjecAgent. The same model flips from mostly-executes to mostly-not across benchmarks.
  - Under Authorize, Gemma-4B reaches 72.7% and Gemma-12B 61.4% InjecAgent ASR. Interdict gives 0.0 for both.
  - NF4: Gemma-4B 7.8% (FP16 7.0), Gemma-12B 1.4% (FP16 3.5).
- **Authorize vs Interdict** (§4.2, App. E).
  - Qwen-9B: 773 cases succeed only under Authorize, 1 only under Interdict (chi-square 768.0). Spark-4B goes from 0.95% to 70.88%.
  - Non-responders: LFM-2.6B (0.00%, mostly invalid) and Ministral-14B (0.11%, "remains unexplained").
  - MiniCPM-2B only reaches 2.9% under Authorize (Figure 2) but still counts among the nine significant shifts.
- **Guardrail.** Pooled InjecAgent ASR falls from 9.69% to 0.95% (9 agents), and invalid outputs fall. Ministral-14B rises from 0.28% to 4.39% (p < 1e-10) and LFM-2.6B from 0.00% to 0.57% (§4.2).
- **Quantization is heterogeneous** (Figure 2, my reading). The pooled decline hides agents that rise:
  - Ministral-14B: 0.3% (FP16), 5.7% (FP8), 4.6% (NF4)
  - Nemotron-Nano-4B: 2.6% (FP16), 4.8% (NF4), p = 9e-4, "described but not interpreted"
  - Gemma-4B: 7.0% (FP16), 7.8% (NF4)
- **ATOM** (Figure 3a, Table 11).
  - All agents: S0U1 67.2%, S0U0 21.7%, S1U1 3.8%, S1U0 7.3%. ASR 11.1 is the bottom-row sum; UA 71.0 is the left-column sum.
  - Equal NRP (Qwen-9B 81.0, Nanbeige-3B 80.6, Spark-4B 80.6) hides different ATOM profiles (Table 5):
    - Qwen-9B: 11.5% unsafe, 10.1% S0U0
    - Spark-4B: 1.7% unsafe, 22.5% S0U0
- **Task completion after a failed attack** (Table 10): Refusal 83.20% (n=2,643), Inert-U 77.74% (10,365), Inert-R 71.88% (704), Breakdown 11.95% (251). Behavior vs completion: chi-square 1,272.6. So one in six refusals still leaves the task undone.
- **Frontier reference** (App. F).
  - Kimi K3 AgentDojo: 4/949 attacks succeed; of 935 judged failures, 96.6% Refusal, 0.5% Inert-U, 2.9% Breakdown.
  - Kimi K3 InjecAgent: 0 successes; of 1,053 failures, 99.0% Refusal. One run of one model.
- **Judge validation** (Table 8, App. D).
  - Two authors labeled 150 trajectories and resolved disagreements by consensus. Against the judge:
    - Action level: 100% agreement.
    - Four-way: 96.0% [91.6, 98.2], kappa 0.835.
    - Six-label: 86.0%, kappa 0.662. The InjecAgent six-label subset is weakest (77.33%, kappa 0.594). Most disagreements are Inert-U vs Inert-R.
  - Agreement with the benchmarks' own verdicts: 96.7% (AgentDojo) and 98.5% (InjecAgent). The judge labels 99.7% and 99.8% of recorded successes as compliance.
- **Verified-on-first-attempt quotes only:** Exec.|Rec. becomes 28.1% (AgentDojo) and 16.2% (InjecAgent) (App. F).
- **Judge-benchmark disagreements.** On benchmark-scored failures, the judge says compliance in 3.6% (AgentDojo) and 1.6% (InjecAgent). Ministral-14B is the largest: AgentDojo Full 6.1%; InjecAgent Partial 7.9% and Full 6.9% (Table 2). The paper does not resolve which side is right.

## Limitations

**The authors':**
- Two synthetic single-agent benchmarks with static injections; no adaptive, white-box or multi-agent attackers.
- Greedy decoding, so sampling variance is not measured.
- Tool interfaces differ across agents.
- The frontier reference is one run of one model.
- One LLM judge; Inert-R and Inert-U are hard to separate.
- Recognition is read from stated reasoning and is a lower bound.
- Task completion exists only on AgentDojo.
- The policy conditions ran only on InjecAgent, so their utility cost is unmeasured.

**Mine:**
- **"Ignored" is inferred from silence.** Inert-U means the reasoning never names the injection as an instruction. The authors concede that reasoning is unfaithful (Turpin et al. 2023), so some "ignored" cases may be unverbalized recognition. The headline "ignored, not refused" partly rests on reading chain-of-thought silence as non-processing. Nothing measures whether the injected content influenced the trajectory at all, for example by removing it and replaying.
- **No counterfactual removal.** No case is replayed without the injection, so "the agent continued the task as if the injection were absent" is never tested against the injection-free trajectory.
- **Authorize conflates two things.** It is an operator instruction to execute tool-output tasks. Following it shows the models obey the system prompt over a data/instruction boundary, which an instruction hierarchy arguably wants. It is weaker evidence that the baseline is "inactivity" than the paper suggests.
- **"Only nine words" is about length.** The two prompts differ by nine words in length (163 vs 172) but are opposite in content.
- **Untriggered Default is shown only on InjecAgent.** The policy result comes from the two-turn, single-decision setting. Whether it holds in multi-turn AgentDojo is untested.
- **Denominator mismatch.** The 8.09% baseline is pooled over all 11 x 1,054 FP16 cases, while the Authorize/Interdict comparison uses 10,698 matched cases.
- **Recognition counts are ambiguous.** "Flagged recognition in 4,740 + 5,688 trajectories" (§4.1) equals the 10,428 "recognition claims" before verification (App. D), yet up to 962 claims failed the first quote check. It is unclear how many were finally downgraded.
- **A verbatim quote proves presence, not meaning.** A negated sentence ("this is not an injection") could pass. The 150-item human check and the six-label kappa of 0.662 (InjecAgent 0.594) bound but do not remove this.
- **A cited support was revised.** The paper cites Leong (2026, arXiv 2608.28502) for "agents can recognize forged authority yet still act on it" and describes it as detecting recognition with probes and forced reflection. arXiv v2 of that paper (updated 17 Oct 2026, new title "Instruction Self-Arbitration Is Not a Trust Boundary...") now reports:
  - Its original keyword flag for fabricated authority mostly matched negated phrases; blind judges flagged fabricated authority in at most 1 of 150 responses.
  - Doubt-and-delete responses are rare after reflection (25/509).
  - Its crossed-probe test halted without interpretable evidence.

  So part of this paper's related-work support for "recognition is not resistance" has been walked back. Its own Table 4 numbers stand on their own judge. I checked the v2 abstract via the arXiv API, not the full text.
- **Gemma 4 31B was not tested,** only E4B and 12B, and they used a text-JSON wrapper rather than native tool calls.

## Assumptions the paper does not test

- That the absence of verbalized recognition means the injection was not processed.
- That the judge's verbatim-quote rule captures recognition semantics (negation, hedging).
- That benchmark verdicts are the right reference when the judge disagrees (Ministral-14B).
- That the system-prompt effect generalizes beyond InjecAgent's two-turn format.
- That greedy decoding at one seed is representative of a sampled deployment.
- That the text-JSON wrapper vs native function calling does not drive cross-agent differences (it is acknowledged but not ablated).

## How it overlaps each component of the idea

- **C1 (setting): partly.** Small open-weight tool-using agents, including Gemma-4-E4B-it and Gemma-4-12B-it, with NF4 4-bit serving tested. No coding agent, no repository, no code graph, no issue repair. Context is not a binding constraint (65k max length, 8 turns).
- **C2 (delivery, pull vs push; presentation): not covered.** Weak analog only: the same tool-output content is executed at 0.22%, 8.09% or 43.05% depending on a system-prompt framing block (Figure 2). That manipulates how visible content is licensed, not whether it is pulled or pushed, and there is no presentation-format manipulation.
- **C3 (planted wrong relation, scored against a base rate): partly.** It plants adversarial content in tool outputs and scores following (execution of the attacker goal) against ignoring, refusing and breaking down. But the plant is an instruction toward a different goal, not a false relation inside information the user's task needs. It has no base-rate control (how often the agent would reach the target without the plant), which is trivially near zero for attacker IBANs and is not trivial for a code location.
- **C4 (paired forks from one saved state): partly, weak.** Paired same-case comparisons across conditions with greedy decoding, fixed seeds and McNemar. But these are full re-runs, not forks from a saved mid-trajectory state, with no shared prefix and no short continuations.
- **C5 (visible vs queryable; tool calls or stated beliefs are not evidence of use): partly, strong on the stated-belief half.** It measures "said" (verified chain-of-thought recognition quote) separately from "did" (attacker tool call). Recognized-then-executed is 28.9% (AgentDojo) and 16.9% (InjecAgent); silent non-action dominates failures (76-80%); a frontier model behaves differently (96.6-99.0% refusal). It does not test visible vs queryable.
- **C6 (market agents, monitors): not covered.** Loose analog: §1 notes that only refusal leaves an auditable signal while ignoring "leaves no trace", so a monitor reading messages sees refusals and misses silent non-compliance. Recognized-then-executed also means a reasoning monitor would see the right words while the action goes wrong.

## Pointers for our design (my inferences, labeled as guesses)

- **Fix and report the framing of pushed graph context.** Guess: a system-prompt sentence calling the pushed graph "verified" vs "hints" could swing following more than the delivery channel does, given the 0.22% vs 43.05% swing here from a one-block prompt change. Hold it constant across C2 arms, or make it an explicit factor.
- **Reuse the six-way label scheme for decoy responses.** Map follow, recognize-and-follow, recognize-and-reject, ignore and breakdown onto it, and reuse the verbatim-quote verification. Add negation handling and a human check, given the Leong v2 correction.
- **Report interface failures separately per arm.** Invalid outputs and breakdowns masquerade as safety here (LFM-2.6B). NF4 raised invalid outputs for Qwen-4B (19 to 115), and the 4-bit Gemma 31B can do the same. This matches the project rule on interface failures.
- **Gemma 4 acts on tool-output instructions readily once licensed** (E4B 72.7%, 12B 61.4% under Authorize), and Gemma-12B's Exec.|Rec. is 67.5% on AgentDojo. Guess: Gemma 4 31B will follow pushed graph content at high rates. Plan the decoy arm's power around a large effect.

## What it does NOT do that the idea needs

- No code, repository, code graph, or end-to-end repair task.
- No manipulation of how the same information reaches the agent (tool call vs context) and no presentation-format factor.
- No planted false relation inside task-relevant information, and no base-rate comparison against the true-information condition.
- No forks from a saved mid-trajectory state with a shared prefix; no measurement of where the agent reads or edits next.
- No measure of influence that does not rely on verbalization, such as removal-and-replay or forced-choice continuations.
- No binding context limit; no Gemma 4 31B.
