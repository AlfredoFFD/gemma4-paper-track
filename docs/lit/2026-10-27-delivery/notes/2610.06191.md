# Judged Useless, Queried Anyway: Tool-Using Agents Rarely Turn Their Own Evidence Judgments into Stopping Decisions

- **arXiv:** 2610.06191 (v1, 05 Oct 2026, cs.AI, CC BY 4.0)
- **Authors:** Chubin Zhang, Zhenglin Wan, Xingrui Yu, Jingxuan Wu, Yaxin Zhou, Ivor Tsang, Bo An (NTU Singapore, NUS, A*STAR CFAR/IHPC, UNC-Chapel Hill, CMU)
- **Version read:** v1, full text (HTML-derived txt, 6,102 lines) plus the 37-page PDF, read 2026-10-27
- **Code:** github.com/bennidict23/judged-useless-queried-anyway (MIT); prompts, question manifests, labels to follow
- **Table numbering:** in the appendix, the HTML text's table cross-references are off by one in two places against the PDF. Cite PDF numbers: Table 7 is simulated policies, Table 23 is stated-judgment Δ.

## Verdict on overlap

This is the cleanest prior design for the C5 claim "what the agent judges or says is not what it acts on." It runs on small open models (7-8B, plus 32B) under an 8,192-token context. It also has reusable fork machinery (C4): one-word judgments and belief probes on scratch copies of the conversation, and answer-now branches replayed from the same history. It cuts against the strong form of the idea's C5 in one important way. Writing the decisive statistic (the agent's own running count of useless results) into the visible context did not make 7-8B agents act on it. Only the harness removing actions did. It has no code, no graph, no pull vs push of task information (C2), no false information (C3), and nothing on C6.

## Claim (key numbers and where)

1. **Agents judge correctly but do not act on the judgment.**
   - Side-channel judgments call a failing source's results useless 99.9% (Qwen2.5-7B), 98.4% (Llama-3.1-8B), 99.6% (Qwen3-8B), 99.4% (Qwen3-32B) and 99.9% (Claude Haiku 4.5) of the time.
   - After five consecutive own-useless judgments, the unaided agent answers on 3/122, 1/282, 1/292, 19/284 and 1/284 questions. Otherwise it searches until the budget runs out.
   - Sources: Figure 1 right, §3, App. C.1 test J1.
2. **Stopping does not rise with accumulated useless judgments.**
   - The time-matched contrast Δ (defined under Metrics) is negative for every unaided open model: -0.11, -0.02, -0.06, -0.07 on test300, and -0.09, -0.03, -0.05, -0.06 on fresh300.
   - A hazard model gives β = -0.01 to -0.02 per extra useless judgment for the unaided 7-8B models (Qwen3-32B -0.04), against +0.15 to +0.17 under the enforced rule.
   - Sources: Figure 3, Table 6, Table 10, Table 22.
3. **Telling agents more changes when they stop, not what they stop on.**
   - Permission to answer from memory makes Qwen3-8B stop early regardless of evidence (Δ -0.32).
   - A stated budget moves 7-8B stops to the last action (51-79% of failing-source answers), and a doubled budget moves them from action 8 to 16.
   - A stopping rule stated in words is followed only partly (Llama-3.1-8B Δ +0.09, Qwen3-32B +0.08, against +0.37 and +0.33 enforced).
   - Writing the running count into context (decide) leaves Δ at -0.14 to -0.24.
   - Sources: §4, Figure 3, Figure 4, Table 16.
4. **Harness-enforced integration works.**
   - Removing search and lookup after five consecutive own-useless judgments raises mean6 success for the four open models and Claude Haiku 4.5 by +0.026 to +0.097 (Holm-significant). It also keeps the median answering action at 6 when the budget doubles.
   - It beats a rate-matched random signal by +0.011 to +0.029, so the timing of the signal matters.
   - Sources: §5, Table 15, Figure 4.
5. **The pattern replicates** on 300 fresh questions with Δ pre-registered as the primary endpoint (19/19 tests pass), on FEVER (rule gain +0.129 to +0.201), and on second and third runs. It holds only partly for Claude Sonnet 5 (design-label contrast +0.12 [+0.05, +0.18]). Sources: §6, §7, App. D.4, D.6.

## Method (enough to reproduce)

- **Environment.**
  - HotpotQA distractor dev set. Each question's knowledge base is its own 10 paragraphs (2 gold, 8 distractors).
  - ReAct agent (Thought / Action / Action Input) with `search[query]` (title match, then word overlap), `lookup[keyword]` (next sentence containing the keyword) and `finish[answer]`.
  - Budget of 8 actions (16 in the scaling runs). Correct means token F1 ≥ 0.6.
  - The base prompt states neither the budget nor that an unanswered question counts as wrong (§2, App. B.1).
  - FEVER transfer: 292 balanced claims; knowledge base = evidence pages plus 8 pages from other claims; verdict SUPPORTS or REFUTES.
- **Failure injection.**
  - A failed observation is replaced by a paragraph from another question's knowledge base.
  - Six regimes: clean; persistent; recover_after_c with c in {1,2,3}; late_onset_from_3. Success is averaged with equal weight (mean6).
  - Harder variants: plausible (the question's own distractor paragraphs), answerless (its own pages with every supporting-fact sentence removed), and recover_after_4/5 (§2, §6, App. D.5).
- **Side-channel judgment.**
  - Before each action after the first, the history is copied and the copy asks whether the LAST observation was USEFUL or USELESS for the original question.
  - The reply (at most 8 tokens) is parsed and discarded, so the acting history is unchanged. A reply that is not an explicit USELESS resets the streak.
  - Judgments are recorded live when a condition acts on them. Otherwise they are replayed afterwards on the recorded trajectories. Claude Haiku 4.5's come from its enforced-rule run (App. B.1, C.1).
- **Stated judgments.**
  - Read from the agent's own next thought. They were annotated by two LLM annotators from different families (Claude Sonnet 5 and GPT-5.6-luna; binary kappa 0.903 on stated judgments), with first-author adjudication of the 59 count-changing disagreements.
  - A reference set was labeled by Claude Fable 5.1 and GPT-6-sol. A local Qwen3-32B annotator (binary kappa 0.874) labels test trajectories.
  - No independent human annotators (App. B.2, D.4).
- **Belief probe.** At every decision point, fork the history, ask for p_continue and p_answer_now as JSON (budget unstated), and discard the reply. A usefulness turn is asked on a separate fork (App. B.1, C.4).
- **Answer-now branch.** The same history is replayed with the forced-finish instruction; agents comply at 89-98% of decision points. It gives the realized value of stopping at that point (App. C.4, D.2).
- **Conditions** (each adds one element; App. B.1 has the prompts):

  | Condition | What changes |
  |---|---|
  | none | base prompt |
  | permit | may answer from own knowledge |
  | budget | permit, plus "at most 8 actions … unanswered is wrong" and an "[Actions remaining: n]" counter |
  | stated rule | permit, plus "if five consecutive results are useless, stop and answer" |
  | call cost | budget, plus "+1 per correct answer, -0.05 per search or lookup" |
  | decide | the agent's judgment and running count are written into the history each step, it must output DECISION: CONTINUE or ANSWER_NOW, and is told to act consistently |
  | enforced rule | at a streak of k=5 USELESS, the system prompt says search and lookup are unavailable and the observation is followed by a final-answer instruction |
  | combo | budget plus enforced rule |
  | controls | random (seeded draw at the model's dev USELESS rate) and lexical (USELESS if under 25% of the question's content words are in the first 400 characters; balanced accuracy 0.77) |
  | extra arms | thinking mode; Search-R1; a backup_search tool on an intact KB with a switch rule that disables the failing tool after 5 useless; a stated-judgment rule with a keyword reader on the agent's own thought (precision 0.971, recall 0.913) |

- **Models and serving.**
  - Local via vLLM on 4x RTX A5000: Qwen2.5-7B, Llama-3.1-8B, Qwen3-8B, Qwen3-32B, all without thinking. Qwen3 uses its recommended sampling; the others are greedy.
  - Context is 8,192 tokens, raised to 16,384 or 32,768 only where a trajectory overflowed (Deviations 1, 3, 5).
  - Claude Haiku 4.5 and Claude Sonnet 5 via API, in fewer conditions. Sonnet 5 runs on the first 100 questions with service-default decoding.
  - Search-R1 (Qwen2.5-7B-Instruct, PPO on NQ and HotpotQA) uses its own prompt, greedy.
  - About 350 GPU-hours. No training.
- **Splits.** 100 dev questions set every threshold (k=5 maximized dev mean6). test300 is confirmatory. fresh300 uses a new seed and is disjoint, with Δ as the primary endpoint. FEVER has 292 claims.
- **Statistics.**
  - Paired by question with 2,000 bootstrap resamples (question-clustered for I). Holm across models within a hypothesis. Non-inferiority margin -0.05.
  - Pre-registration and amendments A1-A20 are kept as an append-only document, each frozen before its runs, but not deposited with a third-party registry (App. A).

## Setting, data, models

- **Task.** QA over tiny (10-paragraph) per-question knowledge bases with one primary tool, and fact verification.
- **Agents.**
  - Open models: Qwen2.5-7B, Llama-3.1-8B, Qwen3-8B, Qwen3-32B, Qwen3-8B and Qwen3-32B in thinking mode, and Search-R1.
  - API models: Claude Haiku 4.5 and Claude Sonnet 5.
- **Hard context limit.** 8,192 tokens for the local models.
- **No Gemma, no code, no graph.**

## Metrics (exact definitions)

- **Success and mean6.** Success is the share of questions answered correctly (token F1 ≥ 0.6, or verdict match) in a regime. mean6 is the unweighted mean over the six regimes.
- **Time-matched contrast Δ** (primary; amendment 12):
  - After t results, let s be the current run of consecutive results the agent judged useless.
  - At decisions with 3 ≤ t ≤ 6 (actions 4-7), group (a) has s = t (every result judged useless). Group (b) has 1 ≤ s ≤ t-2: the latest result was judged useless, with an earlier non-useless judgment between the second and second-to-last results.
  - Δ is the Mantel-Haenszel risk difference in answering, (a) minus (b), stratified by t, with the final action excluded.
  - Reading: Δ > 0 means stopping on the useless run; Δ ≈ 0 means stopping by clock or deadline; Δ < 0 means stopping follows earlier useful evidence (App. C.1).
- **Integration index I** = h({4,5}) - h({1,2}), where h is the probability of answering after that many consecutive failed observations. It is pre-registered but confounded with time: a clock policy stopping at action 6 scores +0.50 (Table 7).
- **Design-label contrast.** Persistent minus late_onset_from_3 at the same action, used where judgments are missing.
- **Hazard model** (exploratory). A linear probability model: answering = α_action + α_regime + β·run + γ·earlier_useful + ε, with and without question fixed effects, and a 1,000-resample question-cluster bootstrap (Table 10).
- **Utility.** mean6 - λ·calls, with λ = 0.05. Judgment calls are optionally charged as well.
- **Validation of the stopping measures on simulated policies** (Table 7):
  - Both Δ variants are 0 for never-stop, deadline, clock, and hazard-with-time policies.
  - They are positive for own-judgment count policies with k=3 (own Δ +1.00) and k=5 (+0.38).
  - Neither detects a threshold beyond the budget (k=7 gives 0).

## Results, including weak and negative ones

- **mean6 on test300, raw** (Table 2), for Qwen2.5-7B / Llama-3.1-8B / Qwen3-8B / Qwen3-32B:

  | Arm | Qwen2.5-7B | Llama-3.1-8B | Qwen3-8B | Qwen3-32B |
  |---|---|---|---|---|
  | none | .192 | .263 | .448 | .509 |
  | budget | .328 | .312 | .464 | .581 |
  | enforced | .237 | .328 | .474 | .572 |
  | combo | .375 | .337 | .478 | .578 |

  - Other agents, none to rule: Claude Haiku .501 to .598; Claude Sonnet 5 .632 to .653; Search-R1 .403 to .427.
  - **The budget prompt matches or beats the enforced rule on success** (rule - budget: -.091, +.016, +.009, -.009; Table 15). The paper's case for the rule rests on what stopping responds to and on budget invariance, not on success.
- **Persistent-source success** (Table 13), none vs rule:
  - Qwen2.5-7B .043 vs .100; Llama .000 vs .143; Qwen3-8B .007 vs .153; Qwen3-32B .027 vs .267
  - Claude Haiku .000 vs .380; Claude Sonnet 5 .400 vs .510
- **Stopping would have paid** (exploratory, App. D.2). At the first five-useless point, answering now vs what the agent did:
  - Qwen2.5-7B: 0.171 vs 0.065
  - Llama: 0.159 vs 0.005
  - Qwen3-8B: 0.149 vs 0.013

  Continuing spent 2.5-2.6 extra tool calls. Claude Haiku 4.5, forced at that point, is right on 114 of the 284 questions where the rule fired; unaided it answers 1 of them (§1).
- **Beliefs do not explain it** (App. C.4, Figure 6). The models err in different directions:
  - Qwen3-8B overestimates the value of continuing (self-report about 0.5-0.7 against an ideal observer of about 0.1-0.27).
  - Qwen2.5-7B overestimates the value of answering now (about 0.65-0.78 against a realized 0.07-0.18).
  - Llama underestimates answering now.

  Actions do not follow the reports: where its own report favors answering, Llama answers at 32/595 decision points and Qwen2.5-7B at 267/2,443 (§3).
- **Stated judgments tell the same story.**
  - Stated and side-channel judgments agree at 0.87 / 0.94 / 0.94 / 0.96 (kappa 0.60 / 0.84 / 0.84 / 0.89).
  - Δ from stated judgments is -0.08 / -0.01 / -0.04 / -0.02.
  - After 5 stated-useless judgments, agents answer 0/15, 1/266, 1/287 and 16/252 (Table 23).
  - Qwen3-8B's stated judgments call useless evidence useless 93.9% of the time (n=1,463) and treat useful evidence as such 98.1% (n=212) (App. B.2).
- **Specificity check** (Table 11). Judgments are not just "useless" bias: models call a gold paragraph USEFUL on first retrieval at 0.92-0.98, except Qwen2.5-7B (0.57) and Claude Haiku (0.77).
- **Rule vs controls** (Table 15):
  - Rule vs random: +.011 / +.029 / +.021 (H2 pass).
  - Rule vs lexical: +.012 / -.001 / -.011, so a cheap word-overlap detector is as good as the agent's own judgment (exploratory).
- **Non-inferiority where the source recovers.** 18 of 20 tests pass; Qwen3-8B fails rec1 (lower bound -.057) and rec3 (-.060) (Table 4 H3).
- **Long recovery** (Table 26). The rule loses in recover_after_5 for Qwen3-8B (-.213) and Qwen3-32B (-.137), because k=5 gives up just before recovery.
- **Answerless source.** The budget arm does better than the rule (Table 26).
- **Plausible (on-topic) failures** (Table 8). Judgments are less accurate (84.3-97.5% useless). Unaided answering after 5 useless rises to 2-23% (39/200, 5/207, 26/176, 40/174). The rule still helps.
- **Backup tool** (Table 25).
  - With an intact backup_search described in the prompt, Llama and Qwen2.5-7B switch by the fourth action on only 17% and 49% of questions. Llama's persistent success is 0.05 (clean 0.497). Qwen3-8B and Qwen3-32B switch early.
  - No unaided agent's leaving rises with useless judgments (Δ(leave) at most +0.02). The switch rule, which disables the failing tool, gives +0.26 (Llama) and +0.30 (Qwen3-8B).
- **Decide (running count shown)** (Figure 3, Table 13).
  - Δ is -0.24 / -0.14 / -0.15 (exploratory).
  - Qwen2.5-7B's mean6 rises to .360 and beats the rule (H4 fails, -.123), but by stopping early indiscriminately.
- **Larger, reasoning and RL agents** (§7, Tables 13, 24).
  - Qwen3-32B unaided answers after five useless judgments on 19/284 questions.
  - Under the budget prompt, Qwen3-32B's I rises to +0.32, which fails the pre-registered prediction L-H9. But Δ = 0.00 [-0.06, +0.05], so the rise is time-driven, and a doubled budget adds 46% more tool calls for no gain.
  - Thinking mode: Qwen3-32B answers from memory on 97% of failing-source questions (11% without thinking) and before any real result on 47% of recover_after_2 questions.
  - Search-R1 answers after one or two searches on 27% and searches to the end on 45%. Its judgments failed the pre-registered validity check (89% of real results called useless), so its Δ is not interpreted.
- **Claude models.**
  - Sonnet 5 rule - none is +0.022, p = .051 (S-H1 fail). Its per-step side-channel judgments were not saved for 5 of 6 regimes.
  - Claude Haiku 4.5 with the call cost stated answers on 98.5% of persistent questions and beats the enforced rule on mean6 (+.053) and on utility (+.213). Its design-label contrast is only +0.01, so it answers regardless of the evidence (Table 21).
- **Cost.** The enforced rule makes 3-5 judgment calls per question. If those are charged at the price of a tool call, it becomes the most expensive arm (Table 6). The stated-judgment keyword reader removes these calls with success within 0.01 of the enforced rule (E2) and utility +.236 / +.196 / +.190 over it (E3, Table 20). It does not apply to Qwen2.5-7B: the keyword reader finds a judgment at only 26% of its decision points (0.74 have none), and the rule fires on 0.05 of persistent questions (Table 20).
- **Placeholder answers (an interface failure).**
  - Answers that copied the `finish[answer]` template were scored wrong in the raw analysis. They were concentrated in the arms that stop (for example Qwen3-8B's stated-rule arm: 297 of 2,100).
  - Repair changed no decision in Table 12, but three contrasts changed significance. In the second run, Rp4 for Qwen3-8B passes only after repair; raw stays primary (Table 12, App. C.5, D.6).
- **Run-to-run determinism.** Rerunning unaided arms with identical settings reproduced mean6 within +0.001. Run-to-run variation arises when an intervention changes vLLM's batching (App. A).

## Limitations

**The authors':**
- Failures are simulated by replacing observations in fixed knowledge bases. Natural failures (partial, stale, wrong content) are untested.
- Recovery happens after at most three failures, and k was tuned to that.
- The Claude models got fewer conditions and questions.
- Judgments are elicited on a copy and beliefs are self-reports, so they are compared only within a model.
- LLM annotators with author adjudication, not independent humans.
- Answering from memory is not automatically safe.

**Mine:**
- **The side channel is itself a prompted statement.** A one-word answer on a copy with a new question appended is a stated belief, not a read-out of what the acting policy uses. Agreement with the judgments the agents state in their own reasoning (0.87-0.96) mitigates this but does not settle it.
- **The phenomenon is a meta-decision against a strong default.** ReAct models are trained to keep calling tools, and the base prompt hides the budget. "Do not act on own judgment" may be specific to overriding a default loop (stopping) rather than a general judgment-action gap.
- **Decide is a compound intervention.** It shows the count and also forces a written decision and an instruction to act consistently. It does not isolate "visible count" from "forced deliberation."
- **Off-topic failures are easy.** On-topic failures weaken the judgment side (84-97%), and answering after five useless then reaches 23% (Qwen3-32B plausible). The dissociation is strongest where judging is trivial.
- **Small absolute gains.** On HotpotQA the rule adds +0.026 to +0.097 mean6, and a one-sentence budget prompt matches or beats it on success for 3 of 4 open models.
- **Δ was defined after seeing results** (amendment 12). The fresh300 re-test addresses this. Holm runs only within hypotheses across models, while the paper reports dozens of tests.
- **Possible transcription error.** Table 22's Qwen3-32B "answered after 5 useless" on fresh300 is 19/284, identical to its test300 value (App. C.1). Pre-registered F5 covered only the 7-8B models. To check.
- **The headline count is wider than the evidence.** "Seven agents call failing results useless 97-100%" includes Sonnet 5, whose per-step judgments were not saved for 5 of 6 regimes (App. B.4), and Search-R1, whose judgments failed validity (89% of real results called useless).
- **Claude Haiku's dissociation pairs across runs.** Its 1/284 pairs judgments from the enforced-rule run with actions from the unaided run (API decoding is not deterministic), not a same-trajectory replay.
- **Narrow model and task range.** No Gemma. Tasks are tiny 10-paragraph QA environments with one tool.

## Assumptions the paper does not test

- That a judgment elicited on a forked copy equals the judgment active during acting.
- That the forced-finish answer-now value is reachable by the agent's own policy (compliance is 89-98%).
- That off-topic replacement is representative of real tool failure.
- That k=5 transfers to sources with different recovery profiles. It does not for recover_after_5, by their own test.
- That the gap is not produced by ReAct or tool-use post-training biasing toward continued calls. No base model or differently trained comparison except Search-R1.
- That showing the count without the forced DECISION line would behave the same as decide.

## How it overlaps each component of the idea

- **C1 (setting): partly.** Tool-using ReAct agents on small open models (7-8B, 32B) under a hard 8,192-token context, served with vLLM. No coding, repository, code graph or issue repair. Single-tool QA over 10 paragraphs.
- **C2 (delivery, pull vs push; presentation): partly, as an analog.** There is no pull vs push of the same task information and no presentation-format factor. But it orders interventions in a way directly relevant to C2:
  - available but not forced: the backup tool is taken up late or not at all by Llama (17% switched by the fourth action) and Qwen2.5-7B (49%), and leaving never rises with useless judgments;
  - stated in the prompt: the stated rule is followed only partly;
  - written into visible context each step: decide's running count does not change what the agents stop on (Δ -0.14 to -0.24);
  - enforced by the harness: tool removal works (Δ +0.33 to +0.37; leaving Δ +0.26 / +0.30).

  This is a counterexample to a general "visible carries behavior" claim, at least for 7-8B models and for a stop or switch decision.
- **C3 (planted wrong relation, scored against a base rate): not covered.** Failed observations are useless (off-topic, distractor or answerless), not wrong-but-plausible pointers, and there is no measure of following. The random-signal control (rate-matched random USELESS) is a design pattern for a base-rate comparison. The paper's related work cites arXiv 2609.05587 (Yang et al. 2026) as the work where agents carry corrupted tool returns into answers even when their reasoning notices the conflict; that is the C3-relevant paper.
- **C4 (paired forks from one saved state, short continuations): partly.** Three fork mechanisms on recorded histories:
  - the side-channel judgment on a scratch copy (at most 8 tokens, discarded);
  - belief probes on separate forks;
  - answer-now branches replayed from the same history with forced finish, compared pairwise with the actual continuation at the same decision point (App. D.2).

  It also offers an observational alternative to forks: Δ matches histories at the same step. What it lacks is forks that vary information delivery or truth, and next-location outcomes; its interventions run as full trajectories. Practical warning for our forks: vLLM outputs change when an intervention changes batching (App. A).
- **C5 (visible vs queryable; tool calls or stated beliefs are not evidence of use): covered for the stated-belief half, and contrary evidence for the visibility half.**
  - Covered:
    - Judgments and stated reasoning are accurate (98.4-99.9% useless) while actions ignore them (0.3-6.7% answer after 5 useless).
    - Beliefs do not predict actions (32/595, 267/2,443).
    - Agents keep calling a tool they have judged useless five times in a row, so a tool call is not evidence the agent believes the tool helps.
  - Contrary: making the agent's running count visible did not make 7-8B agents act on it, and only the harness changed behavior. The idea's "what is visible carries behavior" must be scoped. My guess at the scope: visible content that supplies the next step of the default loop (a file to open) may be followed, while visible content that asks the agent to break the loop (stop, switch) is not.
- **C6 (market agents, monitors): not covered.**

## Pointers for our design (my inferences, labeled as guesses)

- **Narrow C5 or test both content types.** This paper is the strongest evidence a judge will raise against "visible carries behavior."
  - Guess: frame C5 as "visible pointers that fit the agent's next step get followed; queryable ones do not get pulled."
  - Add, if cheap, one arm where pushed content asks the agent to deviate (for example "this function is not the bug").
- **Copy the scratch-copy fork pattern** for measuring what the agent believes at a state without perturbing the trajectory, and the answer-now-style branch for counterfactual value. Validate any new metric (for example decoy-following minus base rate) on simulated agents with known policies, as Table 7 does.
- **Control vLLM batching for paired forks.** Run the arms of a pair in the same batch configuration, or accept and measure the drift (the paper's own reruns drift by +0.001 when nothing changes).
- **Track template-copy and format failures as interface failures per arm.** Here they clustered in the arms that change behavior, which biased raw contrasts.

## What it does NOT do that the idea needs

- No code, repository, code graph or end-to-end repair.
- No manipulation of the same task information delivered by tool pull vs context push, and no presentation format (bare names vs signature + file:line).
- No false or decoy information; no measure of following a wrong pointer; no base rate from a true-information arm.
- Forks are used to elicit judgments and to value a forced stop, not to vary delivery or truth from a shared prefix. The outcome is when the agent stops, not where it reads or edits next.
- No Gemma; no 4-bit quantization.
